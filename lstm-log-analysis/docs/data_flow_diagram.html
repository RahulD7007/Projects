1. Parsing & Tokenization dataset.py

Raw text log files are processed through regular expressions or template parsers (e.g., Drain). Variable parameters like IP addresses, timestamps, and user IDs are masked into wildcards <*>, assigning each unique log pattern a discrete integer Event ID.

2. Feature Engineering features.py

Sequential log lines are grouped by Session ID. Overlapping sliding windows of size h (default = 10) extract sequential features where X contains the past h event IDs and y represents the ground-truth next event ID.

3. Deep Learning Architecture train.py

A Stacked LSTM neural network with an Embedding layer learns system grammar exclusively from healthy/normal execution sessions. The output layer applies a Softmax activation to output probability distributions over all possible next events.

4. Top-K Anomaly Scoring predict.py

During inference, if the actual incoming log event is not within the model's top K predicted events, the window is flagged as anomalous. Session scores represent the total fraction of anomalous windows in that session.

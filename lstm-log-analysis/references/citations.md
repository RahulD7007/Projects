# Academic References & Benchmark Citations

## 1. Primary DeepLog Paper

- **Title:** DeepLog: Anomaly Detection and Diagnosis from System Logs through Deep Learning
- **Authors:** Min Du, Feifei Li, Guineng Zheng, Vivek Srikumar (University of Utah)
- **Venue:** ACM SIGSAC Conference on Computer and Communications Security (CCS), 2017
- **Key Concepts:**
  - Log Key Prediction using Stacked LSTMs.
  - Parameter Anomaly Detection using Performance Models.
  - Top-$K$ metric verification strategy ($k=9$).
